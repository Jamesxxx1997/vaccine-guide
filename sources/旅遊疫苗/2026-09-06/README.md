# 旅遊疫苗官方 PDF 資料庫

整理／下載日：2026-09-06。新增 **28 份原始 PDF**，另引用專案既有 **6 份**，共 **34 份、653 頁**。原檔不裁切、不重製、不覆寫。

本索引涵蓋 **30 組疫苗／疾病主題**：常見旅遊疫苗、出國前常規免疫檢視，以及特殊暴露／公衛情境。這不是「所有出國者應打的 30 種疫苗」，也不聲稱囊括全球所有品牌、各國最新核准或台灣現貨。

## 使用方式與目前完成範圍

- 下表連結可直接開啟專案內的 PDF。頁碼均指 **PDF 檔案頁次**，不是原書印刷頁碼。
- WHO 旅遊疫苗總覽是分類起點；實際劑次、年齡、禁忌、孕期／免疫低下限制，必須再核對指定產品、版本及所在地政策。
- 本次完成的是來源入庫與分類索引，**尚未把這批文件接進疫苗網頁的 hover、側欄或黃色高亮**。沒有新增臨床判斷規則。
- 下列章節起點及 `manifest.json` 的 `text_heading_page_candidates` 僅協助尋找段落，**不是逐句核實或高亮座標**。機器命中也可能是目錄、交叉引用或參考文獻。
- 不因「某國有某疾病警示」就自動判定每位旅客需接種；還需評估地區、季節、停留／活動、暴露、免疫史與個人禁忌。

## 必須保留的版本／法域差異

1. **下載日期不等於版本日期。** 英國資料採 PDF 內章節日期；EMA 的產品資訊項目更新時間與整個網頁時間分開。FDA 本批 VIMKUNYA、TICOVAC、JYNNEOS 原檔的 `Revised` 欄分別仍是 `X/XXXX`、`M/YYYY`、`MM/YYYY`，版本未解，不補造日期。
2. **台灣狂犬病新函與舊說明不能混用。** 2026-03-26 函將旅客暴露期間、免疫狀態及職業暴露分開；本次僅入庫，不將其中某一時程套給所有使用者。
3. **屈公病不能只看一張舊表。** 美國 CDC 說明 IXCHIQ 於 2025-08 暫停、2026-01 撤回；歐盟仍有自己的高感染風險使用條件與年長／共病嚴重不良反應警語。兩者並陳，不以歐盟文件抵銷美國狀態。[CDC 當期疫苗說明](https://www.cdc.gov/chikungunya/hcp/vaccines/index.html)、[EMA Ixchiq](https://www.ema.europa.eu/en/medicines/human/EPAR/ixchiq)
4. **台灣舊黃熱病 PDF 保留為歷史來源。** [原有 2014 文件](../../各疫苗/黃熱病疫苗接種相關說明.pdf)未刪改；本次不以它冒充現行完整指引，另提供 WHO／英國來源。台灣核准、供應與當期醫界公告仍應另核對。
5. **來源入庫不代表台灣已核准或供貨。** 國際仿單、WHO 公衛建議、旅客適用與台灣政策，是不同層次的證據；本次沒有完成所有國際產品的台灣許可證查核。
