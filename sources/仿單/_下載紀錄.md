# TFDA 中文仿單下載紀錄

**建檔日期：2026-09-13**
**目的：**「疫苗過敏與成分」「疫苗副作用（%）」查詢頁需要每一格可回溯至原件 PDF 的原句黃框，
本檔記錄台灣各疫苗產品 TFDA 中文仿單 PDF 原件的下載狀態與來源。

## 下載機制（可重現，已用 curl 實測驗證）

1. **找許可證字號**：用 WebSearch／既有 memory／食藥署開放資料集比對品名，取得完整格式的許可證字號
   （例如「衛部菌疫輸字第001251號」，**不能只用數字**）。當 WebSearch 找不到時，改查食藥署開放資料集
   （見下方「新發現」）比對中英文品名，比 WebSearch 準確。
2. **直連查詢頁**：將完整許可證字號 URL-encode 後 GET（純 curl 即可，**不需登入、不需 CAPTCHA**）：
   ```
   https://mcp.fda.gov.tw/im_detail_1/<urlencoded完整許可證字號>
   ```
   回傳頁面內嵌完整仿單文字（可核對品名/禁忌是否正確），並含 PDF 連結：
   - `href="/insert/pdfcasefile/i_<uuid>"` — 優先，通常是完整仿單全文 PDF。
     **但不保證**：偶有連結雖屬此路徑、實際內容仍是「外盒、仿單、標籤粘貼表」掃描件（如 Priorix），
     每份都要實際打開核對，不能只憑路徑分類。
   - `href="/insert/lablefiles/<uuid>?c=2"` — 次選，常常只是外盒/標籤比對表（行政審查用），
     不含適應症/禁忌/不良反應等仿單正文。
   - 少數許可證（如 PPV23 000492 號）會 302 導向 `/im_detail_pdf/<同證號>`，導向後頁面結構相同，照樣可用。
   - 若頁面完全沒有上述 PDF 連結，但頁面本文（去 HTML tag）仍有「禁忌」「適應症」等段落，
     代表仿單內容只以網頁形式呈現、無獨立 PDF → 依規則**不可用網頁列印稿冒充 PDF 原件**，列為「需手動」。
3. **下載後驗證**：確認開頭 `%PDF`；`pdftotext` 抽取後 grep 品名與「禁忌/不良反應/成分」字樣；
   若為掃描件或向量美工稿（pdftotext 抽不出文字，常見於 GSK/默沙東的 Ricoh 掃描件或 Illustrator 印刷稿），
   改用 `pdftoppm` 轉圖後目視核對內容與品名；`pdfinfo` 記錄頁數；`shasum -a 256` 記錄雜湊。

### 已知陷阱
- `info.fda.gov.tw` 網域目前 **DNS 無法解析（NXDOMAIN）**，此網域已不可用。
- `mcp.fda.gov.tw/im`（關鍵字/品名搜尋頁）需要圖形驗證碼（cpt1）+ CSRF token，**不可繞過**，
  必須先從別處取得許可證字號才能用直連網址下載。
- `im_detail_1/<純數字>`（缺「衛部/衛署...字第...號」全文）會導向搜尋首頁，不是有效查詢。
- **食藥署開放資料集**（無需 CAPTCHA、無需登入）比 WebSearch 更可靠，用於解不出證號時比對：
  - `https://data.fda.gov.tw/data/opendata/export/37/json` — 現行未註銷藥品許可證（實際是 ZIP 包 JSON）
  - `https://data.fda.gov.tw/data/opendata/export/36/json` — 全部藥品許可證（含已註銷）
- 「專案核准輸入／專案進口」疫苗（COVID-19 全系列、Jynneos、Stamaril、Typhim Vi 等）完全不在
  `mcp.fda.gov.tw` 一般藥證體系內，查無許可證字號是正常結果，非查詢失敗；仿單須向疾管署旅遊醫學門診
  或廠商索取。
- 醫院藥品查詢網站上抄錄的許可證字號可能是錯誤/過期資料（例如 Typhim Vi 被誤植為「衛署藥製字000457」，
  直接驗證是無效號碼），一律以 `mcp.fda.gov.tw` 直連結果為準，不可盡信二手網站。
- 已註銷的許可證頁面仍可能保留有效的 PDF 下載連結（如 Tetraxim 001014 號已註銷但仿單全文 PDF 仍可下載），
  只要 fda.gov.tw 網域直連有效即可採用，不因「已註銷」標記而排除。
