# 疫苗搜尋與旅遊建議工作區 — 2026-09-06

## 範圍

本輪僅更新既有本機介面與 loopback 旅遊服務，未部署雲端後端。保留 GitHub Pages 架構；未修改原 PDF、CSV、臨床規則或資料快照。無病人條件傳送到 CDC。

- 疫苗搜尋：50 組既有整理資料（16 旅遊／產品說明、20 篩檢疫苗、14 成人時程）。不是全部 PDF 全文搜尋，也不索引病人推算結果。
- 同一搜尋結果保留產品／地區政策限制、規則 stop/warn/info、PCV 銜接和抗體判讀分支。內文指定 S9/S12 等來源不能被成人 S4 預設值覆蓋。
- `ReferenceUI` 提供共用绑定與清除介面，證據 WeakMap 與分級保持私有。新功能使用同一真實 PDF／CSV 預覽，不建立假 PDF 或新高亮門檻。
- 旅遊評估位於個人風險卡片下方，左側個人條件不會自動套用成旅遊接種處方。

## 資料規則

三模式共用一個目的地評估狀態；切換模式、新搜尋、框內字詞變更和錯誤清除舊資料與來源面板。

- 快照：疫情原列與處方箋原列各自綁定國名、疾病／疫苗、日期、等級、行政區與 CSV 版本。
- A：只根據本次匿名即時搜尋結果；不偷偷加入舊快照處方箋。
- B：後端將**同一份已驗證官方回應**的完整列放入 inert template，框內依請求序號帶回主頁。保留國名、疾病、行政區、等級、發布日期、URL、取得時間；不擷取目前顯示的分頁，不截斷前 200 筆，也不另發第二次官方搜尋。
- 疾病／顯示所有查詢先選目的地。只對唯一完整國名命中自動選擇。
- 全球警示獨立呈現；名稱近似但身分未確認者保留原名與歧義警告，不模糊合併。
- 同日同地同疾病不同等級顯示衝突，不自行判定優先。
- 疫苗卡片按 guide 合併，多個疫情／處方箋理由保留。沒有已整理 guide 的疾病仍列出，明示未收錄不表示無疫苗／無風險。瘧疾標為預防用藥，不改成旅客疫苗。
