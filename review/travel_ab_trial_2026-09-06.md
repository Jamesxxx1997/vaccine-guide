## 修正與檢查

- 初次 B 因官方 unobtrusive AJAX 自動附加 `X-Requested-With=XMLHttpRequest` 失敗；加入這個精確固定欄位的相容處理，轉送前移除。不得接受任意其他表單或臨床欄位。失敗那次不納入成功速度。
- verifier 第一輪抓到：部分／空結果誤判、authority-form 路徑污染 origin 判斷、錯誤被晚到 load 訊息覆寫、後端稍後啟動無法重連。四項均修正並加入回歸；後續再修正空結果殼外的前／後錯誤文字。
- 獨立 verifier Helmholtz 最終 bounded recheck：**localhost-only PASS**，7/7 backend 測試＋frontend 回歸通過，先前問題均解決。此結果不是公開部署許可或全面臨床政策認證。
- 真實本機 HTTP 邊界測試：`//other.test/...` 回400、外部 Origin 的 `/api/search` 回403、非本機 Host 回403，均未對外轉送。
- `npm test` 原有23組介面／6993來源檢查／1022動態分支／2018 CSV映射等均通過。新增 backend 固定上游、正常匿名表單、未知格式拒絕、欄位／路徑限制；前端 A/B 包含延遲結果、模式切換、失敗、跨來源訊息、重新連線與即時PDF導覽測試。
- 本機代理保留正常 TLS 憑證驗證，不碰官方伺服器設定，不使用使用者的官方登入資料。自己的 iframe 限制僅允許本機疫苗站；不得將本機程式直接綁到公網。
